# อภิธานศัพท์

## ส่วนนี้ใช้ทำอะไร

คำอธิบายสั้น ๆ ของคำที่ใช้ในคู่มือนี้ เรียงตามตัวอักษรภาษาอังกฤษตามที่เห็นบนหน้าจอ

| คำศัพท์ | ความหมาย |
|---|---|
| **AED** (ดิรฮัม) | เงินดิรฮัมของ UAE ทุกจำนวนเงินในระบบ CRM เป็นสกุล AED |
| **Area shown on the website** (พื้นที่ที่แสดงบนเว็บไซต์) | การตั้งค่าของสาขาสำหรับชื่อพื้นที่ที่เว็บไซต์ของคุณแสดง เช่น "Dubai Marina, Dubai" มีฉบับภาษาอาหรับให้กรอกได้ตามต้องการ หากเว้นว่างจะใช้เมืองจากที่อยู่ เว็บไซต์ใช้เฉพาะพื้นที่ของสาขาหลัก (บทที่ 6 และ 28) |
| **Ask AI** (ถาม AI) | ผู้ช่วย AI ในแถบด้านบน (Premium) คุณถามคำถามเกี่ยวกับสปาด้วยภาษาพูดธรรมดา แล้ว AI จะตอบจากข้อมูลของคุณเอง |
| **Audit log** (บันทึกการตรวจสอบ) | บันทึกการเปลี่ยนแปลงสำคัญทุกอย่างในสปาของคุณ: ใครทำอะไร และเมื่อใด (บทที่ 30) |
| **Authenticator app** (แอปยืนยันตัวตน) | แอปบนโทรศัพท์ เช่น Google Authenticator, 1Password หรือ Authy ที่แสดงรหัส 6 หลักสำหรับการยืนยันตัวตนสองขั้นตอน |
| **Auto-confirm** (ยืนยันอัตโนมัติ) | การจองออนไลน์จากลูกค้าที่กลับมาใช้บริการ ซึ่งได้รับการยืนยันทันทีโดยไม่ต้องรอคุณ (บทที่ 6) |
| **Backup code** (รหัสสำรอง) | รหัสใช้ครั้งเดียวที่ใช้แทนแอปยืนยันตัวตนได้หากโทรศัพท์หาย แต่ละรหัสใช้ได้ครั้งเดียว |
| **Blocklist** (บัญชีดำ) | การติดธงลูกค้าที่ทีมไม่ควรรับจอง ทีมจะเห็นคำเตือนเมื่อลูกค้ารายนี้จอง (บทที่ 13) |
| **Booking reference** (รหัสการจอง) | รหัสสั้นของการจอง เช่น YJVAC คุณค้นหาด้วยรหัสนี้ได้ |
| **Booking request** (คำขอจอง) | สิ่งที่ลูกค้าส่งจากแบบฟอร์มจองของดีไซน์เว็บไซต์ที่มีแบบฟอร์มของตัวเอง คำขอจะเข้ามาที่ **Enquiries** (ข้อความจากเว็บ) พร้อมทรีตเมนต์ ระยะเวลา วันที่ เวลา จำนวนลูกค้า และพนักงานนวด คำขอจองยังไม่ใช่การจอง คุณยืนยันทาง WhatsApp แล้วเพิ่มลงในปฏิทินเอง (บทที่ 17) |
| **Booking widget** (วิดเจ็ตการจอง) | ปุ่มที่คุณเพิ่มลงในเว็บไซต์อื่น ปุ่มนี้จะเปิดหน้าจองออนไลน์ของคุณในป๊อปอัป (บทที่ 12) |
| **Branch** (สาขา) | สถานที่ตั้งหนึ่งแห่งของสปา มีปฏิทิน ห้อง แคชเชียร์ และวันทำการของตนเอง การมีมากกว่าหนึ่งสาขาต้องใช้แผน Premium (บทที่ 28) |
| **Buffer** (เวลาเผื่อ) | เวลาว่างเป็นนาทีก่อนหรือหลังทรีตเมนต์ เพื่อเตรียมห้องหรือเปลี่ยนผ้าปู (บทที่ 7) |
| **Business day** (วันทำการ) | วันที่การขายหรือการจองนั้นนับเข้า วันทำการสิ้นสุดตามเวลาที่ตั้งไว้ใน **Business day ends at** (เวลาสิ้นสุดวันทำการ) ไม่ใช่เที่ยงคืน ยอดขายช่วงดึกจึงนับเข้าวันที่ถูกต้อง |
| **Campaign** (แคมเปญ) | ข้อความ WhatsApp ที่เขียนสำหรับกลุ่มลูกค้า เช่น ข้อเสนอชวนกลับมาใช้บริการหรือข้อเสนอวันเกิด (Premium บทที่ 25) |
| **Click-to-send** (กดเพื่อส่ง) | วิธีที่ระบบ CRM ส่งข้อความ WhatsApp: ระบบเขียนข้อความและเปิด WhatsApp ให้ แล้วคนเป็นผู้กดส่ง |
| **Commission** (ค่าคอมมิชชัน) | จำนวนเงิน AED ที่พนักงานนวดได้รับจากการจองที่เสร็จสิ้น กรอกไว้ในการจอง (บทที่ 11) และจ่ายผ่านรอบเงินเดือน |
| **Daily close (Z-report)** (ปิดยอดประจำวัน) | การนับเงินในลิ้นชักเก็บเงินตอนสิ้นวัน เทียบกับยอดที่แคชเชียร์คาดว่าควรมี การปิดยอดจะล็อกวันนั้น (บทที่ 14) |
| **Duplicate** (ลูกค้าซ้ำ) | โปรไฟล์ลูกค้าสองรายการที่ดูเหมือนเป็นคนเดียวกัน เช่น มีเบอร์มือถือเดียวกัน คุณรวมโปรไฟล์ได้ (บทที่ 13) |
| **Equipment** (อุปกรณ์) | ชุดอุปกรณ์หรือเครื่องที่ทรีตเมนต์ต้องใช้ เช่น ชุดหินร้อน การจองแต่ละครั้งจะกันอุปกรณ์ที่ว่างไว้หนึ่งชุด (บทที่ 7) |
| **Gift card** (บัตรของขวัญ) | ยอดเงินที่ชำระล่วงหน้าพร้อมรหัส เช่น ABCD-EFGH ใช้เป็นวิธีชำระเงินตอนชำระเงิน (บทที่ 15) |
| **HTML design** (ดีไซน์ HTML) | ไฟล์ดีไซน์เว็บไซต์สำเร็จรูปที่สตูดิโอของเราอัปโหลดให้เว็บไซต์ของคุณ และแสดงตรงตามที่ออกแบบไว้ทุกประการ เช่น ดีไซน์ที่ทำขึ้นสำหรับสปาของคุณโดยเฉพาะ เมื่อสตูดิโอของเราเชื่อมต่อดีไซน์กับแดชบอร์ดของคุณแล้ว ดีไซน์นี้จะดึงเมนู ทีมงาน และช่องทางติดต่อจากแดชบอร์ดแบบเรียลไทม์ (บทที่ 24) |
| **Intake form** (แบบฟอร์มสุขภาพ) | คำถามด้านสุขภาพและคำยินยอมที่ลูกค้าลงนามบนแท็บเล็ตก่อนทรีตเมนต์ครั้งแรก แบบฟอร์มที่ลงนามแล้วจะเก็บเป็น PDF (บทที่ 13) |
| **Liability** (หนี้สิน) | เงินที่ลูกค้าจ่ายล่วงหน้า (แพ็กเกจ สมาชิกรายเดือน บัตรของขวัญ) ซึ่งยังไม่ได้ใช้ เงินนี้จะกลายเป็นรายได้เมื่อมีการใช้ |
| **Live (website)** (ออนไลน์) | เว็บไซต์ของคุณเผยแพร่แล้วและลูกค้ามองเห็นได้ ในหน้า **Website** (เว็บไซต์) ป้ายจะแสดง **Live** ก่อนหน้านั้นจะแสดง **In progress** (กำลังสร้าง, บทที่ 24) |
| **Membership** (สมาชิกรายเดือน) | แผนรายเดือนที่มีจำนวนครั้งรวมไว้และส่วนลดสมาชิก (บทที่ 15) |
| **No-show** (ไม่มาตามนัด) | ลูกค้าที่ไม่มาตามการจอง |
| **Occupancy** (อัตราการใช้งาน) | พนักงานนวดของคุณมีงานเต็มแค่ไหน: ชั่วโมงที่พนักงานนวดถูกจอง เทียบกับชั่วโมงกะงาน |
| **Owner** (เจ้าของ) | บทบาทที่เข้าถึงสปาของคุณได้ทั้งหมด รวมถึงการสมัครใช้งานและบทบาท |
| **Package** (แพ็กเกจ) | ชุดการใช้บริการที่ชำระล่วงหน้า เช่น 5 × Deep tissue 60 การมาแต่ละครั้งจะใช้หนึ่งครั้ง (บทที่ 15) |
| **Pending** (รอยืนยัน) | การจองที่ยังไม่ได้ยืนยันหรือยังไม่เสร็จ การจองออนไลน์เริ่มต้นในสถานะรอยืนยันจนกว่าคุณจะยืนยัน |
| **Permission** (สิทธิ์) | สิ่งหนึ่งที่บทบาทได้รับอนุญาตให้ทำ เช่น **Take payments** (รับชำระเงิน) หรือ **View accounts** (ดูบัญชี, บทที่ 9) |
| **Plan** (แผน) | การสมัครใช้งานของคุณ: **Standard** หรือ **Premium** (บทที่ 1) |
| **Premium** | แผนที่มี AI และระบบอัตโนมัติ Instagram เครื่องมือการตลาด และใช้ได้มากกว่าหนึ่งสาขา ค่าติดตั้ง AED 14,000 + AED 3,000 ต่อเดือน ไม่รวม VAT |
| **Promo code** (โค้ดส่วนลด) | รหัสส่วนลดสำหรับข้อเสนอ เช่น RAMADAN20 (บทที่ 15) |
| **PWA (installed app)** (แอปที่ติดตั้ง) | ระบบ CRM ที่ติดตั้งบนโทรศัพท์หรือคอมพิวเตอร์ของคุณเหมือนแอป ตั้งชื่อตามสปาของคุณ (บทที่ 4) |
| **QR code** (คิวอาร์โค้ด) | รหัสสี่เหลี่ยมที่กล้องโทรศัพท์สแกนได้ ใช้บนบัตรกำนัลและโปสเตอร์สำหรับจอง |
| **Read-only** (อ่านอย่างเดียว) | สถานะที่แดชบอร์ดของคุณจะเข้าสู่เมื่อใบแจ้งหนี้ค่าบริการแพลตฟอร์มค้างชำระเกินระยะผ่อนผัน คุณดูได้แต่เปลี่ยนแปลงอะไรไม่ได้ เว็บไซต์และการจองออนไลน์ยังทำงานตามปกติ (บทที่ 29) |
| **Refund** (การคืนเงิน) | เงินที่คืนให้ลูกค้าหลังการขาย คุณคืนเงินก่อน แล้วจึงบันทึก (บทที่ 14) |
| **Request a change** (ขอแก้ไข) | แบบฟอร์มในหน้า **Website** (เว็บไซต์) สำหรับขอให้สตูดิโอของเราเปลี่ยนส่วนใดก็ได้ของเว็บไซต์นอกเหนือจากสิ่งที่มาจากแดชบอร์ดของคุณ (เมนู ราคา ทีมงาน ช่องทางติดต่อ และเวลาทำการ) สตูดิโอจะตอบกลับใน **Your requests** (คำขอของคุณ, บทที่ 24) |
| **Role** (บทบาท) | ชุดสิทธิ์ที่สมาชิกในทีมมี: Owner (เจ้าของ), Manager (ผู้จัดการ), Receptionist (พนักงานต้อนรับ), Therapist (พนักงานนวด), Accountant (นักบัญชี), Content editor (ผู้ดูแลเนื้อหา) หรือบทบาทกำหนดเอง (บทที่ 9) |
| **Shift** (กะงาน) | ชั่วโมงที่พนักงานนวดทำงานในวันหนึ่ง ลูกค้าจองพนักงานนวดได้เฉพาะในช่วงกะงานเท่านั้น (บทที่ 8) |
| **Show on website** (แสดงบนเว็บไซต์) | สวิตช์ในแบบฟอร์มพนักงานนวด เฉพาะพนักงานที่เปิดสวิตช์นี้เท่านั้นที่แสดงบนเว็บไซต์ของคุณ บนดีไซน์ HTML พนักงานต้องมีรูปด้วย สวิตช์นี้ปิดอยู่สำหรับพนักงานใหม่ (บทที่ 8) |
| **Skills** (ทักษะ) | บริการที่พนักงานนวดทำได้ ลูกค้าจองพนักงานนวดคนนั้นได้เฉพาะบริการเหล่านี้ (บทที่ 8) |
| **Slug (web address)** (ที่อยู่เว็บไซต์) | ชื่อสั้นของสปาที่อยู่ในที่อยู่เว็บ เช่น "serenity" ใน serenity.spamanagement.co |
| **Standard** | แผนที่มีฟีเจอร์หลักครบทุกอย่างและหนึ่งสาขา ค่าติดตั้ง AED 9,000 + AED 2,000 ต่อเดือน ไม่รวม VAT |
| **Tax invoice** (ใบกำกับภาษี) | ใบเสร็จที่มี VAT ใบกำกับภาษีอย่างย่อจะพิมพ์ออกมาสำหรับทุกการขาย ใบกำกับภาษีเต็มรูปจะเพิ่มชื่อ ที่อยู่ และ TRN ของลูกค้า (บทที่ 14) |
| **Template (WhatsApp)** (เทมเพลตข้อความ WhatsApp) | ข้อความมาตรฐานของข้อความ WhatsApp แต่ละประเภท ทั้งภาษาอังกฤษและภาษาอาหรับ พร้อมตัวแปร เช่น {first_name} (บทที่ 16) |
| **Tip** (ทิป) | เงินที่ลูกค้าให้เพิ่มจากค่าบริการ ทิปเป็นของพนักงานนวด |
| **TRN** | Tax Registration Number: เลขประจำตัวผู้เสียภาษี VAT 15 หลักของธุรกิจที่จดทะเบียน VAT ใน UAE |
| **Turn list** (ลำดับคิว) | ลำดับพนักงานนวดของวันนี้สำหรับลูกค้าวอล์กอิน เพื่อแบ่งลูกค้าวอล์กอินอย่างเป็นธรรม (บทที่ 10) |
| **Two-step verification (2FA)** (การยืนยันตัวตนสองขั้นตอน) | การเข้าสู่ระบบด้วยรหัสผ่านพร้อมรหัส 6 หลักจากโทรศัพท์ของคุณ (บทที่ 5) |
| **VAT** (ภาษีมูลค่าเพิ่ม) | ภาษีมูลค่าเพิ่ม 5% ใน UAE ราคาในระบบ CRM รวม VAT แล้ว |
| **Void** (ยกเลิกรายการขาย) | การยกเลิกการขายที่บันทึกผิดในวันที่ยังไม่ปิดยอด การขายนั้นจะถูกตัดออกจากยอดรวมของวัน (บทที่ 14) |
| **Waitlist** (คิวรอ) | ลูกค้าที่รอทรีตเมนต์ในวันที่จองเต็ม เมื่อมีช่วงเวลาว่าง ระบบจะเตรียมข้อความ WhatsApp ไว้ให้ (บทที่ 11) |
| **Walk-in** (ลูกค้าวอล์กอิน) | ลูกค้าที่เดินเข้ามาโดยไม่ได้จอง (บทที่ 10) |
| **Website studio** (สตูดิโอเว็บไซต์) | เมนูที่มีหน้า **Website** (เว็บไซต์) และคลัง **Media** (คลังสื่อ) ของคุณ ทีมสตูดิโอของเรา (ทีม spamanagement.co) ออกแบบ เขียน และเผยแพร่เว็บไซต์ของคุณ ส่วนคุณดูแลเมนู ทีมงาน และช่องทางติดต่อให้เป็นปัจจุบัน (บทที่ 24) |
| **Win-back target** (ลูกค้าที่ควรชวนกลับ) | ลูกค้าที่ไม่ได้มาใช้บริการ 60 วันขึ้นไป |
| **WPS** | Wage Protection System: ระบบคุ้มครองค่าจ้างของ UAE สำหรับจ่ายเงินเดือนพนักงานผ่านธนาคาร (บทที่ 20) |
