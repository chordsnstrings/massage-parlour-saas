# 4. ติดตั้งระบบ CRM เป็นแอป

## บทนี้ใช้ทำอะไร

เปิดสปาของคุณได้ในแตะเดียว แบบเต็มหน้าจอ บนโทรศัพท์ แท็บเล็ต หรือคอมพิวเตอร์ ไม่ต้องใช้แอปสโตร์ แอปจะตั้งชื่อตามสปาของคุณ เช่น **Serenity Management** และใช้โลโก้สปาของคุณเป็นไอคอน

## ติดตั้งบน Android หรือคอมพิวเตอร์ (Chrome, Edge)

1. เข้าสู่ระบบแล้วเปิดสปาของคุณ
2. ในหน้า **Dashboard** (แดชบอร์ด) อาจมีคำแนะนำ **Install *app name*** (ติดตั้ง *ชื่อแอป*) ปรากฏขึ้น กด **Install app** (ติดตั้งแอป) หรือกด **Not now** (ไว้ทีหลัง) เพื่อซ่อนคำแนะนำนี้

   ![คำแนะนำการติดตั้งในหน้าแดชบอร์ด](../../../shots/spa/c04-s01-a.png)

   *ในภาพหน้าจอ:*

   1. คำแนะนำ **Install Serenity Management** (ติดตั้ง Serenity Management)
   2. **Install app**
   3. **Not now**

3. หรือเปิดเมนูโปรไฟล์ (ชื่อของคุณที่ด้านบนของเมนูด้านซ้าย) แล้วกด **Install app**

   ![ปุ่ม Install app อยู่ในเมนูโปรไฟล์ด้วย](../../../shots/spa/c04-s01-b.png)

   *ในภาพหน้าจอ:*

   1. **Account & security** (บัญชีและความปลอดภัย)
   2. **Switch spa** (เปลี่ยนสปา)
   3. **Install app**
   4. **Sign out** (ออกจากระบบ)

4. ยืนยันในหน้าต่างของเบราว์เซอร์ แอปจะปรากฏบนหน้าจอหลักหรือเดสก์ท็อปของคุณ

> **เคล็ดลับ:** ชื่อแอปคือคำแรกของชื่อสปาตามด้วยคำว่า "Management" เช่น "Serenity Spa & Wellness" จะเป็น **Serenity Management** หากชื่อขึ้นต้นด้วย "The" หรือ "Al" ระบบจะข้ามคำนั้น เช่น "Al Noor Spa" จะเป็น **Noor Management**

> **เคล็ดลับ:** ไอคอนคือโลโก้สปาของคุณ หากไม่มีโลโก้ ไอคอนจะแสดงอักษรย่อชื่อสปาบนพื้นสีเขียวมะนาว เพิ่มโลโก้ได้ที่ **Settings** (ตั้งค่า) → **Spa profile** (ข้อมูลสปา, บทที่ 6)

ปุ่ม **Install app** จะปรากฏเฉพาะเมื่อเบราว์เซอร์ของคุณติดตั้งแอปได้ หากไม่เห็นปุ่มนี้ อาจเป็นเพราะติดตั้งแอปบนอุปกรณ์นี้ไว้แล้ว

## ติดตั้งบน iPhone หรือ iPad (Safari)

1. เปิด **app.spamanagement.co** ใน Safari แล้วเข้าสู่ระบบ
2. กด **Install app** (ติดตั้งแอป) หรือ **Show me how** (ดูวิธีติดตั้ง) ขั้นตอนจะปรากฏขึ้น
3. แตะปุ่มแชร์ในแถบเครื่องมือของเบราว์เซอร์
4. เลื่อนลงแล้วแตะ **Add to Home Screen** (เพิ่มไปยังหน้าจอโฮม)
5. แตะ **Add** (เพิ่ม) แอปจะปรากฏบนหน้าจอหลักของคุณ
6. กด **Got it** (เข้าใจแล้ว) เพื่อปิดขั้นตอน

   ![ขั้นตอนการติดตั้งบน iPhone](../../../shots/spa/c04-s02-a.png)

   *ในภาพหน้าจอ:*

   1. ขั้นตอนที่ 1: แตะปุ่มแชร์
   2. ขั้นตอนที่ 2: แตะ **Add to Home Screen**
   3. ขั้นตอนที่ 3: แตะ **Add**
   4. **Got it**

> **สำคัญ:** บน iPhone การแจ้งเตือนจะทำงานเฉพาะจากแอปที่ติดตั้งแล้วเท่านั้น ไม่ใช่จาก Safari ให้ติดตั้งแอปก่อน แล้วจึงเปิดการแจ้งเตือน (บทที่ 5)

หากอินเทอร์เน็ตหลุด แอปจะแสดงข้อความ "You're offline" (คุณออฟไลน์อยู่) กด **Try again** (ลองอีกครั้ง) เมื่อกลับมาออนไลน์แล้ว
