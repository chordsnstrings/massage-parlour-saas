# 16. AI models, AI usage and budgets

## What this is for

Choose which AI model each feature uses, and keep each spa's AI spend inside its monthly budget. The AI comes from BytePlus ModelArk (the Seed 2.0 models by default). AI and Instagram automation for spas are part of the Premium plan.

## AI models

Each AI feature in the platform is called an **agent**. The **AI models** page says which model each agent uses and what that model costs.

1. Click **AI models** in the sidebar. The page says: "BytePlus ModelArk model per agent. Seed 2.0 by default — model IDs change often, so update them here, no deploy needed."
2. Read the table. Each row is one agent:
   - **Agent**: the feature's name, for example **Instagram DMs & booking**, with its short code under it (for example dm_agent).
   - **Model**: the ModelArk model ID it uses.
   - **Price (USD)**: what the model costs per million tokens, for example "0.2500 in · 2.0000 out /1M".
   - **Status**: **On** or **Off**.

   ![AI models per feature.](../../../shots/platform/ai-models-page.png)

   *In the screenshot:*

   1. **Agent**.
   2. **Model**.
   3. **Price (USD)**.
   4. **Edit**.

3. To change a row, click **Edit**. A sheet opens with the agent's name at the top.
4. Change what you need:
   - **Model ID**: copy it exactly from ModelArk.
   - **Input $/1M**, **Output $/1M** and **Cached input $/1M**: the prices per million tokens from ModelArk's price list.
   - **$ per image**: for the image agents.
   - **Supports structured (JSON schema) output**: tick it only if ModelArk says the model supports it.
   - **Enabled**: untick it to switch this agent off for every spa.
5. Click **Save**. A message confirms "Model saved". The change works straight away; no deploy is needed.

The agents are:

| Agent | What it does |
|---|---|
| **Instagram DMs & booking** | Answers Instagram direct messages and helps clients book. |
| **Instagram comment replies** | Suggests replies to Instagram comments. |
| **Google review replies** | Suggests replies to Google reviews. |
| **Instagram content & captions** | Writes post ideas and captions. |
| **SEO** | Search-engine text for spa websites. |
| **Site generator** | Not used at present. |
| **Website Studio AI edits** | **Ask AI** in the editor, **Write texts** and the website import (chapter 10). Switching this agent off turns off all three. |
| **Meta tools assistant (MCP)** | The assistant that uses the Meta (Instagram, Facebook) tools. |
| **Weekly insights** | The weekly summary for spa owners. |
| **Dashboard Ask AI (staff questions)** | Answers staff questions about the spa's own data in the dashboard. |
| **Translation & alt text** | Translations and picture descriptions. |
| **Images (posts, stories)** | Pictures for posts and stories. |
| **Images (hero / premium)** | Large, high-quality website pictures. |

> **Tip:** The prices on this page are used to work out each spa's AI spend. When ModelArk changes its prices, update them here too, or the budgets will be wrong.

> **Important:** The **Model** must be a model ID that exists in ModelArk. A wrong ID makes that feature fail for every spa. If in doubt, ask Claude to check the ID before you save it.

## External Meta MCP server (optional)

The card **External Meta MCP server** is at the bottom of the **AI models** page. You only need it if you use an outside Meta MCP server. The platform's own Meta tools need no setup.

1. Fill in **Server URL**.
2. Fill in **API key**. It is "Sent as a Bearer token." After saving, the field says "A key is stored (encrypted). Leave blank to keep it."
3. In **Allowed tool names**, list the tools the assistant may use, separated by spaces, commas or new lines. Only these tools are offered.
4. Tick **Enabled**.
5. Click **Save**.

To remove the key, tick **Remove the stored key** and click **Save**.

> **Important:** Any tool that would send a WhatsApp message is always dropped, even if you list it. Customer WhatsApp messages stay click-to-send only.

## AI usage and the platform switch

1. Click **AI usage** in the sidebar. The page says: "AI spend per spa against its monthly budget (Asia/Dubai months). At 80 % the spa owner is notified; at 100 % AI pauses for that spa until the 1st."
2. Read the four cards at the top: **Spend this month**, **Last month**, **Calls this month** and **Spas at ≥ 80 %** ("Of their monthly budget").
3. The **Platform AI switch** card says whether AI runs for every spa. The badge reads **on** or **off**.
   - Click **Turn AI off for all spas** to stop every AI call on the platform. A message confirms "AI is off for every spa".
   - Click **Turn AI on** to start it again.
4. Read the table. Each row is one spa:
   - **Spa**: the name, the web address name and a badge: **ok**, **≥ 80 %**, **paused** (the budget is used up) or **AI off** (you switched AI off for this spa).
   - **This month**: the cost, the number of calls and the tokens used.
   - **Last month**: last month's cost and calls.
   - **% used**: how much of this month's budget is used, with a bar. It turns orange at 80 % and red at 100 %.
   - **Budget / month (USD)**: the monthly budget, with a **Save** button.
   - **AI**: **Turn AI off** or **Turn AI on** for this spa only.
5. Click a column heading to sort by it. The list is sorted by **% used** at first.

   ![AI spend per spa.](../../../shots/platform/ai-usage-page.png)

   *In the screenshot:*

   1. The **Platform AI switch**.
   2. **% used**: here 85 %.
   3. The **paused** badge: this spa has used its whole budget.
   4. **Budget / month (USD)** with **Save**.

6. Below the table, choose **This month** or **Last month**. The two tables under it, **By feature (agent)** and **By model**, then show the calls, tokens and cost of all spas together for that month.

> **Important:** At 80 % of its budget, the spa owner gets a notice. At 100 %, AI pauses for that spa until the 1st of the next month (Dubai time). To let it continue now, raise its budget.

> **Tip:** **Turn AI off for all spas** is your emergency stop, for example if ModelArk has a problem or costs suddenly jump. No model is called until you turn it back on. Each spa's own switch and budget stay as they were.

## Set one spa's budget

You can set a budget straight in the **AI usage** table, or open the spa for more detail.

1. On **AI usage**, click the spa's name. Its page opens.
2. Read the cards: **Cost**, **Calls**, **Tokens** and **Budget used (this month)**, for example "85%" and "$21.30 of $25.00".
3. Choose **This month** or **Last month** at the top right to see that month.
4. In **Budget and switch** ("Monthly budget in USD (Asia/Dubai months). 0 = no AI. Changes are audited."), type the new monthly budget in US dollars.
5. Click **Save**. A message confirms it, for example "Marina Pearl Spa: AI budget USD 30 / month".
6. To stop AI for this spa only, click **Turn AI off**. A message confirms "AI off for" and the spa's name. Click **Turn AI on** to start it again.

   ![One spa's AI budget.](../../../shots/platform/ai-spa-detail.png)

   *In the screenshot:*

   1. The budget field and **Save**.
   2. **Turn AI off**.
   3. **Daily cost**: the cost per day this month.

7. Further down, **By feature (agent)** and **By model** show where this spa's AI money went.
8. Click **Performance →** next to the spa's name to open its performance page (chapter 9).

> **Tip:** Every spa starts with a budget of USD 25 a month. The highest budget you can set is USD 10,000. A budget of 0 means no AI for that spa.

> **Tip:** Every budget change is written to the audit log as **platform.ai.budget_updated**, with the old and the new amount (chapter 17).
