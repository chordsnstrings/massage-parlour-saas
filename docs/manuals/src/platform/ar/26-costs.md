# 26. تكاليف التشغيل الشهرية

## الغرض من هذا الفصل

كم تكلّف المنصة شهرياً لتشغيلها، وما الذي يزداد عند إضافة مزيد من مراكز السبا. والهدف هو البقاء عند USD 50 شهرياً أو أقل للخوادم والخدمات.

## الفاتورة الشهرية

| البند | بالدولار الأمريكي شهرياً |
|---|---|
| خادم DigitalOcean (droplet)، ذاكرة 4 GB، ومعالجان (2 CPUs) | 24.00 |
| نسخ الـ droplet الاحتياطية في DigitalOcean، أسبوعياً (يومياً: 7.20) | 4.80 |
| DigitalOcean Spaces (النسخ الاحتياطية الخارجية لقاعدة البيانات) | 5.00 |
| DNS وEmail Forwarding (إعادة توجيه البريد لـ ask@) لدى Namecheap | 0 |
| شهادات الأمان (https) | 0 |
| Resend (بريد الموظفين، باقة مجانية) | 0 |
| Sentry (الأخطاء، باقة مجانية) وأداة لمراقبة التشغيل (مجانية) | 0 |
| GitHub Actions (الفحوصات التلقائية) | 0 |
| **الإجمالي** | **نحو 33.80** |

مع النسخ الاحتياطية اليومية للـ droplet بدلاً من الأسبوعية، يصبح الإجمالي نحو USD 36.20. وأضف إلى ذلك التجديد السنوي لنطاق spamanagement.co لدى Namecheap.

> **نصيحة:** الذكاء الاصطناعي (BytePlus ModelArk) ليس جزءاً من هذه الفاتورة. فهو يُدفع حسب الاستخدام، وتغطيه أسعار الباقات. ولكل سبا ميزانية شهرية خاصة به للذكاء الاصطناعي (الفصل 16).

> **مهم:** للباقات المجانية حدود. فإذا نبّهت Resend أو Sentry أو GitHub إلى اقتراب حدّ ما، فاسأل Claude عما يجب فعله قبل الدفع مقابل ترقية.

## عندما تنمو المنصة

عندما تنضم مراكز سبا أكثر ويصبح الخادم مشغولاً، وسّع الموارد بهذا الترتيب:

1. انقل قاعدة البيانات إلى **DigitalOcean Managed PostgreSQL** (بتكلفة إضافية تبلغ نحو USD 15 شهرياً). وهي تأتي بنسخها الاحتياطية الخاصة وبإمكانية الاستعادة إلى أي لحظة زمنية (point-in-time restore).
2. استخدم **droplet أكبر**، أو أضف خادماً ثانياً للتطبيق.
3. أضف مساحة تخزين أكبر في **Spaces** (خدمة التخزين في DigitalOcean) للنسخ الاحتياطية والملفات.

> **نصيحة:** الصف **Disk** (القرص) في بطاقة **Server health** (حالة الخادم) في صفحة Overview (الفصل 3) هو أول علامة على أن الخادم يحتاج إلى التوسّع. اطلب من Claude أن يراجعه معك قبل أن تغيّر أي شيء.
