# مسرد المصطلحات

## الغرض من هذا الفصل

شروح مختصرة للمصطلحات المستخدمة في هذا الدليل، مرتبة أبجدياً حسب اسمها الإنجليزي كما يظهر على الشاشة.

| المصطلح | المعنى |
|---|---|
| **AI assistant connector** (موصِّل مساعد الذكاء الاصطناعي) | العنوان https://app.spamanagement.co/api/mcp الذي يتيح لـ Claude أو ChatGPT تعديل مواقع مراكز السبا كمسودات. ولا يستطيع ربطه إلا محررو المواقع بالذكاء الاصطناعي الذين فعّلوا التحقق بخطوتين (الفصل 11). |
| **Application** (طلب الانضمام) | النموذج الذي يرسله سبا جديد من spamanagement.co للانضمام إلى المنصة. وتقبله أو ترفضه في **Applications** (الفصل 4). |
| **Area shown on the website** (المنطقة الظاهرة على الموقع) | إعداد الفرع، مع نسخة عربية اختيارية، الذي يحدد اسم المنطقة الذي يعرضه موقع بتصميم HTML، مثل "Dubai Marina, Dubai". وإذا كان فارغاً، تُستخدم المدينة من العنوان. ولا يُستخدم إلا اسم منطقة الفرع الرئيسي. |
| **ARR** (الإيرادات السنوية المتكررة) | الإيرادات السنوية المتكررة (Annual recurring revenue): القيمة السنوية لجميع الاشتراكات النشطة، وتظهر في صفحة Overview (النظرة العامة). |
| **Ask AI** (اسأل الذكاء الاصطناعي) | المساعد الذكي في محرر الصفحات. ويغيّر مسودة الصفحة عندما تصف له التغيير. ولا ينشر أبداً. |
| **Audit log** (سجل التدقيق) | سجل كل تغيير أُجري في لوحة الإدارة، وكل تغيير أجراه المشرفون العامّون في لوحات تحكم مراكز السبا: من، وماذا، ومتى (الفصل 17). |
| **Authenticator app** (تطبيق المصادقة) | تطبيق على الهاتف (Google Authenticator أو 1Password أو Authy) يعرض الرمز المكوّن من 6 أرقام للتحقق بخطوتين. |
| **Automatic billing** (الفوترة التلقائية) | الفحص اليومي الذي ينقل السبا المتأخر عن السداد عبر المراحل: متأخرة السداد، ثم فترة السماح، ثم للقراءة فقط (الفصل 7). |
| **Backup code** (الرمز الاحتياطي) | رمز يُستخدم مرة واحدة بدلاً من تطبيق المصادقة إذا فقدت هاتفك. |
| **Billing rules** (قواعد الفوترة) | الإعدادات التي تحدد متى تُعتبر الفاتورة متأخرة السداد ومدة فترة السماح (**Company** → **Billing rules**). |
| **Booking request** (طلب حجز) | ما يرسله الضيف من نموذج الحجز في تصميم موقع له نموذجه الخاص. ويصل إلى **Enquiries** (الاستفسارات) لدى السبا مع العلاج، والمدة، والتاريخ، والوقت، وعدد الضيوف، والمعالِج. وهو ليس حجزاً: فالسبا يؤكده عبر واتساب ويضيفه إلى التقويم. |
| **Built-in template** (القالب المدمج) | أحد تصاميم المواقع الـ 23 التي تأتي مع المنصة. |
| **Business date** (تاريخ يوم العمل) | اليوم الذي تنتمي إليه عملية بيع أو حجز. ويتبع وقت إغلاق السبا، وليس منتصف الليل، فتُحتسب المبيعات المتأخرة ليلاً في اليوم الصحيح. |
| **Change request** (طلب تعديل) | تعديل في الموقع يطلبه السبا من صفحة **Website** (الموقع) الخاصة به. وتراه تحت **Websites** (المواقع)، وتغلقه بزر **Mark done** بنتيجة **Done** (منجز) أو **Declined** (مرفوض)، مع ملاحظة للسبا (الفصل 10). |
| **CNAME / TXT record** (سجل CNAME / TXT) | نوعان من سجلات DNS. يضيف السبا سجل TXT لإثبات ملكيته لنطاقه، وسجل CNAME لتوجيه النطاق إلى موقعه الإلكتروني. |
| **Configuration card** (بطاقة الإعدادات) | بطاقة في صفحة Overview توضح ما إذا كان كل إعداد من إعدادات الخادم موجوداً، دون أن تعرض قيمته أبداً. |
| **Console** (لوحة الإدارة) | لوحة إدارة المنصة على admin.spamanagement.co، ولا يستخدمها إلا المشرفون العامّون. |
| **Contract design (CRM contract)** (تصميم بعقد بيانات CRM) | تصميم HTML فيه كتلة window.CRM_DATA أو وسم crm-endpoint. ويأخذ اسم كل سبا وشعاره وعلاجاته وأسعاره وفريقه وهواتفه وعنوانه ومنطقته وساعات عمله مباشرة من نظام إدارة السبا (CRM). و**CRM contract v2** (عقد بيانات CRM، الإصدار 2) هو الإصدار الحالي (الفصلان 10 و12). |
| **Conversion** (معدل التحويل) | نسبة زيارات الموقع التي انتهت بحجز إلكتروني. |
| **Deploy** (التحديث على الخادم) | تحديث الشيفرة البرمجية للمنصة على الخادم الفعلي (الفصل 19). |
| **Design report** (تقرير التصميم) | السطر الذي يظهر لتصميم HTML عند الرفع، وعند رفع إصدار جديد، وفي بطاقة **Pages** (الصفحات) لدى السبا. ويبيّن ما إذا كان التصميم متصلاً بنظام الإدارة، وكم قيمة ونصاً في الصفحة يمكن تغييرها، وتحذيراته. ولا يمنع أي شيء أبداً (الفصل 12). |
| **DNS** | دليل عناوين الإنترنت. وتخبر سجلات DNS المتصفحات بالخادم الذي يستجيب لنطاق ما (الفصل 20). |
| **Draft** (مسودة) | نسخة محفوظة من صفحة لا يستطيع الزوار رؤيتها بعد. وتصبح منشورة عندما تنشرها. |
| **Enquiry** (استفسار) | رسالة تُرسَل من صفحة Contact (التواصل) على spamanagement.co (الفصل 5). |
| **Feature flag** (مفتاح الميزة) | مفتاح تشغيل وإيقاف لميزة، مع قيمة افتراضية لكل مراكز السبا واستثناءات اختيارية خاصة بكل سبا (الفصل 14). |
| **Feature tier** (مستوى الميزات) | مجموعة الميزات المتاحة للسبا: Premium أو Standard. ويستطيع المشرف العام منح ميزات Premium لسبا يُفوتر على Standard، أو العكس، دون تغيير السعر. |
| **Fill the CRM from the design** (ملء نظام الإدارة من التصميم) | ينسخ علاجات تصميم HTML وصوره وأوصافه وصور فريقه إلى نظام إدارة السبا. ويمكن إنشاء العلاجات غير الموجودة بسعر عند الطلب، ولا تتغير الأسعار أبداً (الفصل 10). |
| **Free address** (العنوان المجاني) | عنوان موقع السبا على spamanagement.co، مثل saffron-spa.spamanagement.co. ويعمل دائماً. |
| **Global section** (القسم المشترك) | قسم محفوظ من الموقع يظهر في عدة صفحات. عدّله مرة واحدة فتتحدّث كل الصفحات. |
| **Grace period** (فترة السماح) | الأيام التي تلي تأخر سداد الفاتورة وتسبق تحوّل لوحة تحكم السبا إلى وضع القراءة فقط. |
| **HTML design** (تصميم HTML) | موقع من صفحة واحدة صُمّم خارج المنصة ورُفع كملف حجمه حتى 5 MB. ويُحفَظ ويظهر تماماً كما صُمّم. ويمكن تغيير كلماته وصوره لكل سبا في **Website content** (محتوى الموقع)، ويُحدَّث لكل مراكز السبا بإصدار جديد (الفصلان 10 و12). |
| **Legacy plan** (الباقة السنوية القديمة) | **Yearly (legacy)**: الباقة القديمة بسعر AED 24,000 سنوياً. وتحتفظ بها مراكز السبا الحالية حتى تاريخ تجديدها، ولا تستطيع مراكز السبا الجديدة اختيارها. |
| **Namecheap** | الشركة المسجَّل لديها نطاق spamanagement.co، والتي تشتري منها النطاقات لمراكز السبا. |
| **Off-site backup** (النسخة الاحتياطية الخارجية) | نسخة من قاعدة البيانات مخزَّنة بعيداً عن الخادم، حتى تبقى البيانات إذا فُقد الخادم (الفصل 22). |
| **Own domain** (النطاق الخاص) | نطاق يملكه السبا، مثل www.theirspa.ae، ويُستخدم لموقعه بدلاً من العنوان المجاني. |
| **Payment plan** (خطة الدفع) | طريقة فوترة الاشتراك: **12 monthly invoices** (12 فاتورة شهرية) أو **One-time annual** (دفعة سنوية واحدة). |
| **Payment reminder** (تذكير بالدفع) | رسالة تُنشئها في صفحة السبا وترسلها بنفسك عبر واتساب. وتُظهر للسبا أيضاً شريطاً أحمر. |
| **Payment schedule** (جدول الدفعات) | جميع فواتير فترة الاشتراك، تصدر دفعة واحدة. |
| **Pause** (إيقاف مؤقت) | جعل لوحة تحكم السبا للقراءة فقط، وعادةً بسبب التأخر في الدفع. ويستمر موقعه الإلكتروني وحجزه الإلكتروني في العمل. |
| **Phone fixes** (إصلاحات الهاتف) | خيار لكل تصميم HTML. وعند تشغيله، تضيف المنصة إعداد عرض للهاتف وتُبقي الصور والعناصر العريضة داخل شاشات الهواتف. وهو متوقف افتراضياً، فيظهر التصميم مثل الملف تماماً (الفصل 12). |
| **Placeholder** (عنصر نائب) | كلمة بين أقواس معقوفة مزدوجة، مثل {{spa_name}} أو {{crm_data_url}}، تحل محلها البيانات الخاصة بكل سبا في تصميم HTML. |
| **PLATFORM_ADMIN_EMAILS** (قائمة المشرفين العامّين) | إعداد الخادم الذي يحتوي على عناوين البريد الإلكتروني المسموح لها بأن تصبح مشرفين عامّين. |
| **Plan** (الباقة) | ما يدفعه السبا والميزات التي يحصل عليها: **Premium** (رسوم تأسيس AED 14,000 + AED 3,000 شهرياً) أو **Standard** (رسوم تأسيس AED 9,000 + AED 2,000 شهرياً)، غير شاملة ضريبة القيمة المضافة. |
| **Preflight** (فحوصات ما قبل النشر) | الفحوصات التي تعمل قبل نشر الصفحة. والأخطاء تمنع النشر، أما التحذيرات فلا تمنعه. |
| **Prepaid liability** (الالتزامات المدفوعة مسبقاً) | قيمة بطاقات الهدايا وباقات الجلسات والعضويات التي دفع العملاء ثمنها ولم يستخدموها بعد. |
| **Preview link** (رابط المعاينة) | رابط يتيح لأي شخص رؤية مسودة الصفحة دون تسجيل الدخول. وتنتهي صلاحيته بعد 1 أو 7 أو 30 يوماً. |
| **Primary domain** (العنوان الأساسي) | العنوان الذي يستخدمه موقع السبا. وعندما يكون النطاق الخاص هو الأساسي، يوجّه العنوان المجاني الزوار إليه. |
| **Publish** (النشر) | جعل مسودة الصفحة منشورة ليراها الزوار. والمشرفون العامّون وحدهم ينشرون، فالسبا لا يراجع موقعه ولا يوافق عليه. |
| **Read-only** (للقراءة فقط) | لوحة تحكم سبا يمكن عرضها ولا يمكن تغييرها. وتبقى صفحة الفوترة تعمل. |
| **Recorded, never processed** (تُسجَّل ولا تُعالَج أبداً) | قاعدة الدفع في المنصة: تسجّل مراكز السبا ما دفعه العملاء نقداً، أو بجهاز البطاقات الخاص بها، أو بتحويل بنكي. ولا يحصّل نظام إدارة السبا أي مبلغ من العميل أبداً. |
| **Red bar** (الشريط الأحمر) | الشريط الأحمر الذي يراه السبا عندما تكون هناك فاتورة متأخرة السداد أو تذكير بالدفع مفتوح. |
| **Resend** | خدمة البريد الإلكتروني التي تستخدمها المنصة لإرسال رسائل الموظفين، مثل روابط تسجيل الدخول والتنبيهات (الفصل 15). |
| **Restore drill** (تجربة الاستعادة) | الاختبار الشهري الذي يستعيد أحدث نسخة احتياطية في قاعدة بيانات تجريبية لإثبات أن النسخ الاحتياطية تعمل (الفصل 22). |
| **RevPATH** | الإيراد لكل ساعة متاحة للمعالِج: الإيرادات دون ضريبة القيمة المضافة مقسومة على ساعات المعالِجين. |
| **Roll out** (التعميم) | اعتماد إصدار قالب منتظر. فيصبح ذلك الإصدار إصدار القالب، وينتقل إليه فوراً كل سبا منشور على إصدار أقدم. وتُنقل تعديلاته، ويستطيع كل سبا التراجع عنه بزر **Undo** (تراجع) في صفحة الاستوديو الخاصة به (الفصل 12). |
| **Sentry** | الخدمة التي تجمع تقارير الأخطاء من المنصة (الفصل 23). |
| **Setup fee** (رسوم التأسيس) | رسوم تُدفع مرة واحدة عند انضمام السبا، وتصدر في فاتورة مستقلة. |
| **Show on website** (الظهور على الموقع) | مفتاح لكل معالِج في نموذج الموظفين لدى السبا. ولا يظهر على موقع السبا إلا من فُعّل له (ومن له صورة، في تصاميم HTML). وهو متوقف افتراضياً. |
| **SITE_AI_EDITOR_EMAILS** (قائمة محرري المواقع بالذكاء الاصطناعي) | إعداد الخادم الذي يحدد المشرفين العامّين المسموح لهم باستخدام **Ask AI** و**Write texts** وموصِّل مساعد الذكاء الاصطناعي (Claude أو ChatGPT). وقيمته على المنصة الفعلية "*": أي كل مشرف عام فعّل التحقق بخطوتين، ولا يلزم بريد إلكتروني موثَّق. وإذا كان قائمة عناوين محددة، فيجب أن يكون العنوان في القائمة وأن يكون موثَّقاً. |
| **Spa CRM / dashboard** (نظام إدارة السبا / لوحة التحكم) | النظام الخاص بالسبا على app.spamanagement.co للحجوزات والعملاء والمبيعات وغير ذلك. |
| **Still from the design** (ما زال من التصميم) | المربع في **Website content** (محتوى الموقع) وفي نافذة النشر الذي يسرد النصوص التي ما زالت تعرض سبا التصميم أو مدينته أو هاتفه أو بريده الإلكتروني أو نص حشو، أو التي ليس لها نص عربي بعد. ولا يمنع النشر (الفصل 10). |
| **Studio template** (قالب الاستوديو) | قالب موقع أنشأته بنفسك، بحفظ موقع سبا، أو استيراد ملف، أو رفع تصميم HTML. |
| **Stripe Checkout** | صفحة الدفع الآمنة من Stripe، ولا تستخدمها مراكز السبا إلا لدفع فواتير منصتك بالبطاقة. |
| **Subscription** (الاشتراك) | اتفاق السبا معك: الباقة، والسعر لكل 12 شهراً، وخطة الدفع، والفترة، والحالة. |
| **Super-admin** (المشرف العام) | شخص في فريقك لديه صلاحية كاملة على لوحة الإدارة. ويحتاج إلى بريد إلكتروني موثَّق وتحقق بخطوتين. |
| **Template version** (إصدار القالب) | ملف أحدث لقالب HTML مرفوع. وعند رفعه عبر **Upload new version** (رفع إصدار جديد)، ينتظر اعتمادك قبل أن يستخدمه أي سبا (الفصل 12). |
| **Turnstile (bot check)** (التحقق من الروبوتات) | فحص من Cloudflare يتأكد من أن من يملأ النموذج العام شخص وليس روبوتاً (الفصل 15). |
| **Two-step verification** (التحقق بخطوتين) | تسجيل الدخول بكلمة مرور مع رمز مكوّن من 6 أرقام من تطبيق المصادقة. وهو إلزامي لكل مشرف عام. |
| **VAT** (ضريبة القيمة المضافة) | ضريبة القيمة المضافة، ونسبتها 5% افتراضياً. وأسعار الباقات غير شاملة الضريبة، وتضيفها الفواتير. |
| **Web address** (عنوان الويب) | الاسم القصير في العنوان المجاني للسبا وفي مسار لوحة تحكمه، مثل saffron-spa. ويمكن تغييره عبر **Rename** (تغيير العنوان). |
| **Website content** (محتوى الموقع) | كلمات صفحة تصميم HTML وصورها لسبا واحد، فوق كلمات التصميم وصوره: المشاهد، ونصوص الحجز وواتساب، ونصوص الصفحة مع عنوانها ووصف البحث، والصور. وتمر بالمسودة ثم النشر، بالإنجليزية والعربية، ولا يتغير ملف التصميم أبداً (الفصل 10). |
| **Website status** (حالة الموقع) | موضع موقع السبا في صفحة **Websites** (المواقع): **Not started** (لم يبدأ) أو **Template chosen** (تم اختيار القالب) أو **Draft** (مسودة) أو **Live** (منشور)، إضافة إلى "Unpublished changes" (تغييرات غير منشورة) (الفصل 10). |
| **Website Studio** (استوديو المواقع) | صفحة في لوحة الإدارة (**Websites** ثم اسم السبا) يصمّم فيها المشرفون العامّون موقع السبا ويعدّلونه وينشرونه. ويُفتح محرر الصفحات بملء الشاشة (الفصل 10). |
| **WhatsApp click-to-send** (الإرسال عبر واتساب بنقرة) | الطريقة الوحيدة التي تتواصل بها المنصة مع العملاء: تُعدّ رسالة واتساب، ويضغط شخص على Send (إرسال). |
| **Worker** (المعالج الخلفي) | البرنامج الذي يعمل في خلفية الخادم وينفّذ المهام المجدولة: التذكيرات، وفحوصات الفوترة، والنسخ الاحتياطية، وغيرها. |
| **Write texts** (كتابة النصوص) | زر الذكاء الاصطناعي في صفحة استوديو المواقع الخاصة بالسبا، ويكتب مسودة نصوص كل الصفحات بالإنجليزية والعربية من بيانات السبا نفسه. ويكتب أيضاً محتوى الموقع في صفحات تصميم HTML، ويعمل من تلقاء نفسه بعد التبديل إلى تصميم بعقد CRM contract v2 أو تعميم إصدار جديد منه. ولا ينشر أبداً (الفصل 10). |
